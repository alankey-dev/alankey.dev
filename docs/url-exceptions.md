# URL exceptions

Spec FR-032 and SC-008 require that once a post or page is published, its
URL remains permanently resolvable. If a URL must change (rename, removal,
restructure), the original URL MUST keep working via a redirect rule in
`_redirects`, and the change MUST be recorded here.
